Coach Search — keyword vs. semantic vs. hybrid, measured

A company describes what it needs in its own words, for example "conflict resolution for our sales team in Hamburg, on site, max €2,000". The system pulls out the hard constraints, ranks coach profiles, and shows the sentence that made each one match.

  • Graded on 15 hand-labelled queries, each built to test one weakness (synonyms, exact terms, an English query, German compounds): hybrid search reached Recall@5 1.00 and MRR@10 0.90, keyword search alone 0.73 / 0.67
  • BM25 found no correct coach for 4 of 15 queries. Hybrid and semantic search came out tied (MRR 0.90 vs. 0.88, a two-query gap), and the write-up says so
  • Tried sentence-level chunking and kept it out of ranking: it lowered MRR from 0.88 to 0.76 on these short profiles, so it's used only to explain matches

Limits, stated in the repo: 30 synthetic profiles, 15 queries, one person's labels. A 0.07 difference in MRR is a single query.

SmartNotes-AI — lectures in, study notes out

Press Record in the lecture hall and Stop at the end. The Mac transcribes the lecture on-device, an LLM turns it into structured notes, and each lecture merges into one notebook per course — deadlines go into the calendar, and every line links to the second it was said.

  • On-device Whisper (WhisperKit, Core ML): audio never leaves the laptop, and it's recorded in 5-minute chunks so a crash loses nothing
  • The LLM must return JSON that matches a schema (one retry with the error fed back). A deterministic Swift merger with no LLM in it folds each lecture into the notebook. 587 automated checks
  • Resumable five-step pipeline. The notes model is a setting: Claude Code, the Anthropic API, or a local OpenAI-compatible model such as Ollama
  • In progress: an Android companion (Kotlin, on-device Whisper) that records on the phone and syncs through Google Drive. It runs on an emulator but hasn't been tested end to end on a real phone

Designed and directed by me; built with Claude Code as a pair programmer — a written spec, a plan, test-first code and a review for every feature.

RoBERTa-base baseline for Adversarial NLI

Our team asked whether a four-stage training curriculum beats ordinary fine-tuning on ANLI, a benchmark built from examples that fooled earlier models. Answering that needs a fair control. Building it was my part.

  • Fine-tuned RoBERTa-base on all three ANLI rounds: 3 epochs, 10.5 hours on one Apple M4 (MPS), no cloud spend
  • An R1-only ablation and a per-class error analysis alongside the main run
  • Reported the curriculum model as competitive, not dominant: ahead on R1 and R2, behind on the hardest round
